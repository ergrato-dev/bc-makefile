# Labs — Semana 02: Variables y Expansión en Make

| # | Lab | Objetivo | Duración |
|---|-----|----------|----------|
| 01 | [lab-01-variables-basicas](lab-01-variables-basicas/) | Definir y usar variables con los cuatro operadores `=` `:=` `?=` `+=` | ~50 min |
| 02 | [lab-02-expansion-recursiva](lab-02-expansion-recursiva/) | Demostrar que `=` evalúa en el momento de uso y puede referenciar variables definidas después | ~50 min |
| 03 | [lab-03-expansion-inmediata](lab-03-expansion-inmediata/) | Usar `:=` con `$(shell ...)` para capturar valores de shell exactamente una vez | ~50 min |
| 04 | [lab-04-variables-condicionales](lab-04-variables-condicionales/) | Implementar defaults con `?=` que el usuario puede sobreescribir desde CLI o entorno | ~50 min |
| 05 | [lab-05-override-cli](lab-05-override-cli/) | Parametrizar un Makefile de build pasando múltiples variables desde la línea de comandos | ~50 min |
| 06 | [lab-06-variables-rotas](lab-06-variables-rotas/) | Identificar y corregir cuatro bugs de expansión de variables en un Makefile roto | ~50 min |
