# Labs — Semana 05: Funciones de Texto y Archivo

| # | Lab | Objetivo | Duración |
|---|-----|----------|----------|
| 01 | [wildcard](./lab-01-wildcard/README.md) | Descubrir archivos `.c` automáticamente con `$(wildcard)` y eliminar listas hardcodeadas | 50 min |
| 02 | [patsubst](./lab-02-patsubst/README.md) | Transformar listas de fuentes a objetos y otras rutas con `$(patsubst)` y `$(subst)` | 50 min |
| 03 | [filter](./lab-03-filter/README.md) | Seleccionar y excluir subconjuntos de listas con `$(filter)` y `$(filter-out)` | 50 min |
| 04 | [rutas](./lab-04-rutas/README.md) | Extraer directorios, nombres, bases y extensiones con `$(dir)`, `$(notdir)`, `$(basename)`, `$(suffix)` | 50 min |
| 05 | [combinadas](./lab-05-combinadas/README.md) | Combinar todas las funciones en un build system que se auto-configura | 50 min |
| 06 | [funciones-rotas](./lab-06-funciones-rotas/README.md) | Identificar y corregir errores comunes en el uso de funciones de texto | 50 min |

**Total: 5h**

Cada lab incluye `starter/` (código inicial con TODOs) y `solucion/` (referencia). Intenta resolver el lab antes de consultar la solución.
